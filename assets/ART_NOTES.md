# Starling art sources

## Generated UI art

`art/menu_backdrop.png` was generated using the built-in ImageGen tool. It is
background artwork for the live title and result UI. All text and buttons are
Godot controls, so the interface remains interactive and readable.

Complete generation prompt:

> Use case: ui-mockup / stylized-concept. Asset type: production background artwork for the main menu UI of Starling, a small orbital salvage game. Create a beautiful 1536x1024 landscape cinematic game menu BACKGROUND with no typography and no buttons. Art direction: premium miniature hard-surface 3D space illustration, deep midnight navy and muted petrol teal, warm amber starlight, subtle film texture. Composition: left 58 percent is very dark quiet navy negative space for a live UI panel; on the RIGHT third a small beautifully modeled ivory and graphite salvage spacecraft with mint teal cockpit, twin compact thrusters, orange industrial accents, viewed from above at a gentle three quarter angle, nose pointing toward upper left. A few large faceted slate asteroids surround the far right and bottom right, soft golden nebula across upper right, tiny distant stars and faint orbital arcs. Add an elegant restrained sci-fi UI framing motif at the extreme perimeter: very fine mint linework, clipped corners, a few amber tiny indicator dots, giving a functional spacecraft instrument screen feel. Center left must remain dark and empty for readability. The ship and rocks should feel like tangible Blender models with beveled edges and crisp ambient occlusion. No words, no letters, no numbers, no watermarks, no embedded controls. This image will be used as actual UI backdrop in a playable Godot game.

## Original Blender models

The generated image informed the ivory/graphite/mint/orange palette. The actual
meshes were built with Blender's Python API, not generated by ImageGen:

| Model | Contents | Game use |
| --- | --- | --- |
| Starling salvage ship | Beveled fuselage and wings, faceted canopy, twin engines, service panels, cargo straps | Player ship |
| Faceted iron asteroid | Distorted low-poly mesh with varied facets and copper mineral seams | Moving hazards |
| Salvage energy core | Amber hexagonal crystal, graphite end caps, retaining rails, mint charge indicators | Collectibles |
| Relay sentry drone | Vermilion armor, diamond chassis, outriggers, amber optic and thrusters | Telegraphing, charging enemies |

`models/starling_assets.blend` contains the four editable models, materials, lighting,
and an orthographic camera. Each model also has a GLB export and a 256 × 256 RGBA
sprite rendered with Cycles. `art/model_lineup.png` is a render of the library.
Run `tools/build_models.py` through Blender to rebuild all outputs.

## Generated gameplay environment

`art/arena_backdrop.png` was generated with the built-in ImageGen tool for the
three-sector expedition update. Godot draws the interactive dock, grid, hazards,
collectibles, effects, and HUD above it.

Complete generation prompt:

> Use case: stylized-concept. Asset type: subtle playable 2D space-game arena background for Starling. Create a landscape 1536x1024 deep-space environment texture, rich midnight navy and dark petrol blue with very faint teal interstellar dust, a few tiny distant warm stars, soft painterly cinematic volumetric depth. A very small distant partially shadowed pale planet sits in the upper left, taking less than 10 percent of the canvas; faint nebula wisps at the far right. Most of the image must be very dark, spacious and calm with low contrast, suitable behind a top-down arcade game with small bright moving ships, asteroids, and collectibles. The central 85 percent must have excellent gameplay readability. Beautiful high-end science-fiction atmosphere, restrained and elegant. No ships, no asteroids, no rocks, no grids, no UI, no words, no borders, no text, no logos, no watermark. This is an actual tiled-free background layer for the gameplay arena, not a concept screenshot.

## Deep Orbit models

All models use Blender's procedural geometry and Principled materials. The editable
library is `models/deep_orbit_assets.blend`; the individual GLBs retain their
named child nodes for runtime visibility and effects. The ship thumbnails are
transparent Cycles renders, and `art/deep_orbit_sky.png` is a 4096 × 2048 equirectangular sky with a shaded gas giant. `art/leviathan_closeup.png` documents the chase-camera view. The Leviathan points along +Y with its top along +Z; each wreck fragment has its own centered origin.

| Model | Contents | Game use | Required nodes |
| --- | --- | --- | --- |
| `kestrel.glb` | Swept ceramic wings, mint canopy, single large engine | Fast ship frame | — |
| `albatross.glb` | Broad armored hull, cargo pods, four engines | Heavy ship frame | — |
| `salvage_wing.glb` | Compact salvage drone with mint optic | Companion | — |
| `dock_beacon.glb` | Landing pad, mint guide ring | In-sector safe dock | `Ring` |
| `roost_station.glb` | Core ring, landing pad, eight modular additions | Home hub | `Pad`, `Module_Charts`, `Module_Kestrel`, `Module_Albatross`, `Module_Fabricator`, `Module_Plating`, `Module_Broker`, `Module_Rig` |
| `meteor.glb` | Faceted scorched crust and molten emissive fissures | Meteor hazard | — |
| `asteroid_b.glb` | Elongated iron rock and copper seams | Rock hazard | — |
| `asteroid_c.glb` | Clustered iron shards and copper seams | Rock hazard | — |
| `foundry_spire.glb` | Tall refinery shaft, platforms, girders and warning lamps | Sector obstacle | — |
| `gravity_well.glb` | Dark core and amber/violet accretion rings | Gravity hazard | `Ring` |
| `leviathan.glb` | Layered ore hauler with open cargo bays, ore, broken cranes, engine bank, reactor spine and recessed glowing vents | Boss | `Vent_0`, `Vent_1`, `Vent_2` |
| `wreck_fragments.glb` | Six centered pieces of torn hull, truss, container and machinery | Free-flight debris | `Fragment_0` … `Fragment_5` |
| `ring_arc.glb` | Broken 60-degree orbital segment with habitat lights, solar fins and exposed girders | Distant sector dressing | — |

Rebuild the library, exports, sky, thumbnails, and lineup with:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/build_deep_orbit_models.py
```
